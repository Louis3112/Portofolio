# :bangbang: **Personal Portfolio Project** :bangbang:

## :rocket: :art: **Cornelius Louis | Neo-Brutalism Portfolio** :rocket: :art:

This is the official repository for my personal portfolio website. A bold, raw, and interactive digital playground designed to showcase my journey as a **Full-Stack Developer**.

Derived from the **Neo-Brutalism** design trend, this site aims to break the norms of standard "corporate" portfolios. It features high-contrast colors, bold typography, glitch effects, and purposeful animations.

At this stage, the project is **Live & Deployed**. It serves as my main landing page for recruiters, clients, and fellow developers to get to know me better.

### **The Backstory**
Tbh, this is my most ambitious frontend project to date.
Previously, I mostly stuck to basic designs. But after seeing how static standard portfolios can look, I decided to take a **serious approach** with UI/UX.

I wanted to challenge myself to learn **Framer Motion** for complex animations and master **Tailwind CSS** for custom layouts (Grid is harder than it looks!).

There were moments of frustration—especially when deploying to Vercel (Linux case-sensitivity is no joke, my images kept disappearing! :joy:)—but solving those bugs taught me invaluable lessons about file structures and production builds.

**Frameworks & Libraries I am using:**
1.  **Vite + React (TypeScript)** for the lightning-fast framework.
2.  **Tailwind CSS** for the styling engine.
3.  **Framer Motion** for the *Glitch*, *Reveal*, and *Pop* animations.
4.  **React Icons** for the iconography.
5.  **React Type Animation** for the typing effects.

**The Neo-Brutalism Color Palette:**
1.  **#D30000** (Neo-Red - The Primary Accent)
2.  **#000000** (Neo-Black - Borders & Shadows)
3.  **#FFFFFF** (Neo-White - Backgrounds)
4.  **#F3F4F6** (Neo-Gray - Accents)
5.  **#FDE047** (Warning Yellow - Interactive Hints)

## :arrow_forward: **Installation and Usage**
To run this project locally on your machine, please proceed with these steps:

1.  Clone the repository:
    **`git clone https://github.com/Louis3112/portfolio-cornelius.git`**
    *(Make sure to replace with your actual repo link)*

2.  Navigate to the project directory:
    **`cd portfolio-cornelius`**

3.  Type the following command to install dependencies (node_modules):
    **`npm i`**

4.  Run the development server:
    **`npm run dev`**

5.  Vite will start the server. Look for the link **`Local: http://localhost:5173`** (or your specific port) and click it.

6.  Your default browser will open the site automatically. Enjoy the glitch effects!
